# بيانات VITALS-ORBIT الاصطناعية

**SYNTHETIC DATA, research-based. Not real astronaut measurements. Not clinical validation.**

هذه بيانات لأشخاص افتراضيين، وليست سجلات حقيقية لرواد فضاء ولا بيانات رسمية من ناسا. بعض قيمها مستند إلى أبحاث، وبعضها إلى ملخّصات PMData المرفقة بالطلب، والباقي افتراضات موثّقة. لم تُعَد معالجة ملفات PMData الخام في هذا التسليم.

كل ملف مهمة يحتوي على ٢٠ شخصًا افتراضيًا × ١٨٠ يومًا، أي ٣٦٠٠ صف. كل صف يمثل شخصًا واحدًا في يوم واحد. الأسماء AST-001 وما بعدها معرّفات وهمية.

## أي ملف أستخدم؟

| الملف داخل out | الاستخدام |
| --- | --- |
| synthetic-astronauts.csv | النسخة الأساسية مع غياب بعض مواعيد القياس |
| synthetic-astronauts-clean.csv | نفس القراءات الأساسية بلا غياب |
| synthetic-astronauts-tempshift.csv | افتراض ارتفاع حرارة الفم تدريجيًا، لاختبار أثر هذا الافتراض |
| synthetic-astronauts-small.csv | حالات صحية بأحجام أصغر |
| synthetic-astronauts-large.csv | حالات صحية بأحجام أكبر |
| الملفات المنتهية بـ -clean.csv | نسخة كاملة من كل سيناريو |
| synthetic-meta.json | الإعدادات وخطوط الأساس المحسوبة قبل المهمة |
| synthetic-events.json | توقيت الحالات وذروتها وأحجام تأثيراتها |
| synthetic-provenance.csv و .md | مصدر كل معلمة أو الافتراض المستخدم فيها |
| SYNTHETIC-DATA.md | تقرير الإنشاء وفحوصات البيانات وحدود استخدامها |

## الأعمدة

`astronaut_id, mission_day, bp_sys, bp_dia, hr, temp, spo2, glucose, sleep, mood, radiation, exercise, context, events`

الوحدات: الضغط mmHg، النبض bpm، حرارة الفم °C، الأكسجين %، سكر صائم mg/dL، النوم بالساعات، المزاج من ١ إلى ٥ والأعلى أفضل، الإشعاع جرعة فعالة يومية mSv، والتمرين بالدقائق اليومية. الوحدات والنطاقات المقترحة لم تُطابق مع كود التطبيق، لأنه غير مرفق.

السكر مجدول أسبوعيًا. `not_measured` تعني أن القياس غير مجدول، و`missed_checkin` تعني غياب مجموعة القياسات الصباحية معًا، و`missed_dosimeter` تعني غياب قراءة جهاز الإشعاع المسائية. لم تُترك خلايا القياسات فارغة، ولم يُستبدل الغياب بصفر.

عمود `context` يحتوي كائن JSON؛ اقرؤوا ملف CSV أولًا ثم حلّلوا هذا العمود كـ JSON. يحتوي سياق كل مؤشر بشكل منفصل، مثل `After EVA` للنبض والضغط بعد النشاط خارج المركبة. هذه التسميات تحتاج مواءمة مع تسميات التطبيق قبل الإدخال.

عمود `events` يحتوي `none` عند غياب حالة نشطة، أو اسم الحالة ومرحلتها، مثل `infection:rising`. الحالات هي العدوى، فقدان السوائل، نقص النوم، النشاط خارج المركبة، والحدث الإشعاعي الشمسي. هذه سيناريوهات مقصودة وليست تقديرًا لمعدلات حدوثها الحقيقية.

يستطيع أثر نقص النوم على المزاج الاستمرار لليوم التالي. ملف `synthetic-day-labels.csv` يوضح وجود حالة مؤثرة في نوم اليوم السابق، حتى لا تُصنّف كل إنذارات ذلك اليوم مستقبلًا على أنها إنذارات بلا سبب.

## إعادة الإنشاء

من داخل `scripts/synthetic` وباستخدام Python حديث يدعم الإصدار المحدد من NumPy:

```bash
python -m pip install -r requirements.txt
python generate.py
python verify_outputs.py
```

الافتراضات الرقمية كلها في `parameters.py`. استخدموا السجّل نفسه عند تعديل أحجام الحالات أو احتمال غياب القياسات، ثم أعيدوا توليد الملفات. البذرة الافتراضية ثابتة، وتستخدم قرارات الغياب مولّدًا عشوائيًا منفصلًا، لذلك لا تغيّر القراءات الأصلية.

لم نشغّل محرك تنبيهات التطبيق أو التنبؤات، ولا تتضمن الحزمة ادعاءً بدقة طبية أو نتائج لكشف الحالات. تطابق المتوسطات مع مدخلات المولّد لا يُثبت صحة النظام طبيًا.
